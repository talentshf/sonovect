# Sonovect identity

**Sonovect** · **Sound, structured.** · **让声音成为结构化信息。**

Sonovect is a self-hosted ASR service for recordings and video soundtracks, built for application developers. A media upload becomes a durable job, a speech artifact and, when requested, a separate acoustic artifact. The product integrates models; it does not claim authorship of those models.

The logo is the existing **purple butterfly**, adopted from the `brand-management` standard **1.0.0** on 2026-10-20 at the user's request. Use the unchanged [light-background mark](../assets/brand/butterfly-color.svg) or [dark-background mark](../assets/brand/butterfly-dark.svg), with uniform scaling and clear space of at least 4% of its width on all sides. File/version/geometry hashes and usage rules are recorded in the [asset guide](../assets/brand/README.md) and [provenance](../assets/brand/provenance.json).

The README uses the original SVG files directly and switches the supplied variant for the reader's theme. The optional [banner layout](../assets/brand/banner.svg) references the dark version unchanged; keep that source file beside the layout. Sonovect's name and slogan are independent text, not a newly approved fixed combination logo. The surrounding product palette remains dark navy `#0B1626`, periwinkle `#A7B9FF`, and foreground `#F4F7FC`; it does not recolor the butterfly.

Present capabilities through integration, deployment and maintainable outputs. Do not invent customer logos, uptime guarantees, model accuracy, certifications or available hosted plans. No browser workspace or commercial hosted service is included in this version.

Sonovect is the selected project identity; no trademark registration, exclusive rights, public namespace or domain is claimed by this work.

Product positioning, cloud-parity evidence boundaries and prepared repository About/topics live in [positioning](positioning.md). The opening README sections explain inputs, processing choices and outputs immediately after the brand.
