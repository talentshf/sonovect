Debian still lists the two glibc issues and the selected OpenSSL source as unfixed. The OpenSSL vendor has published fixes and schedules fixed releases for2026-12-01; the maintained trixie package remains3.5.7-1~deb13u3. The vendor describes the five OpenSSL issues as low severity; this review preserves the scan's MEDIUM classification. The two new glibc records retain UNKNOWN, despite Debian's minor-issue notes. They are seven additional explicit limitations, extending the retained advisory drift check from10to17records. Upstream changes, new severity/source/digest identities, HTTP/3, general crypto operations, operator code and independent runtimes require renewed assessment.
