# 测试参考与配置建议

[English](quality.md) · [下载参考数据](../evaluation/reference-results.json) · [评分方法](accuracy-evaluation.md)

Sonovect让自己的硬件提供可媲美云端的语音识别。已有同素材对照中，本地Qwen1.7B与两项云端服务的转写质量相当，中文会议的字符错误更少。下面按转写、环境音和实验人声分别列出参考值，保留各自的素材范围、模型和分母。

## 转写路线

测试日期为 **2026-10-21**。本地使用Linux amd64、RTX3090 / 24GiB、Qwen1.7B、配套0.6B对齐器、FireRed语音活动检测和CAM++匿名说话人模型；云端为百炼 `fun-asr`、`qwen3-asr-flash-filetrans`。[公共语料清单](../evaluation/public-corpus.json)记录来源、参考文字和规范化音频摘要：

| 素材 | 本地选择 | 百炼Fun-ASR | 百炼Qwen3-ASR |
| --- | --- | --- | --- |
| 一段39分钟中文会议 | 599/8073字符编辑，错误率7.42% | 678/8073（8.40%） | 628/8073（7.78%） |
| 12段英文语音 | 0/241词编辑 | 1/241 | 0/241 |

三者接收相同的16kHz单声道音频和明确的语言提示，不提供参考答案衍生的热词。CER（字符错误率）和WER（词错误率）按同一人工参考计算替换、删除和插入，失败预测仍保留分母。云端模型别名会变化，这些数字对应所测素材，不代表所有语言、噪声或服务延迟。

10段非语音环境音中，本地、Fun-ASR、云端Qwen分别多识别出3、0、2个字符；数字静音三者均无文字。两项云端对非语音对照分别返回11次和10次失败／无词状态，空文字不改记为任务成功。本地24个任务均完成。

Qwen0.6B在相应素材上为670/8073中文字符编辑、2/241英文词编辑，适合愿意牺牲部分质量换取资源节省的实验部署。无显卡使用FunASR CPU路线；此前同一中文素材测得1005/8073字符编辑（12.45%），作为配置参考，并非新增的同轮云端配对。Paraformer v2.0.9属于配置替代，主权重摘要相同，不应称为重新训练的新模型。

## 环境音

AST负责固定词表内的音频事件标签，MOSS负责独立可选的人声描述，两者不重复分类。既有ESC测试目标命中62/80；早期10条微型验收命中7/10，只能说明该小样本的目标召回，不能说明精确率。另一轮DESED九类测试精确率92.08%、召回率70.63%、类阴性误报24/2665（0.90%），与下述新语料的范围不同。

**2026-10-23** 评测使用[RealDESED官方真实家庭录音](https://zenodo.org/records/20056072)，在预测前固定300条开发集和300条测试集，12个可映射类别，开发集比较12组阈值、候选数量和窗口组合。AST缺少能唯一对应咖啡机、灯开关、窗户开关的标签，这三类是词表缺口；不拿通用“点击”标签凑命中率。其他未标注词表的输出单列，不擅自称为误报或正确。

开发集默认阈值0.1、最多5个标签、10秒窗口的精确率71.73%、召回率49.73%、F1综合分数0.587。改为0.05、最多5个标签、5秒窗口能将召回提高到64.80%，但精确率下降至63.20%；12种组合都未达到预先声明的替换条件。因此保留默认，不拿测试答案继续挑参数。

独立300条测试集按保留默认配置得到：**精确率76.13%、召回率49.43%、F1综合分数0.599**，对应389次正确检出、122次误报、398次漏检。类阴性误报为**122/2813（4.34%）**，描述性Wilson 95%区间3.64%～5.15%。范围内全阴性片段只有2条，虽为0/2误报，其区间上限仍达65.76%，不能宣传零误报；类别单元及同户录音也不完全独立。

| 类别 | 测试阳性数 | 精确率 | 召回率 |
| --- | ---: | ---: | ---: |
| 铃声 | 25 | 61.54% | 32.00% |
| 餐具 | 67 | 81.82% | 67.16% |
| 开关门 | 115 | 70.09% | 65.22% |
| 脚步 | 159 | 91.67% | 6.92% |
| 键盘 | 56 | 89.80% | 78.57% |
| 钥匙串 | 62 | 95.65% | 35.48% |
| 微波炉 | 29 | 100.00% | 51.72% |
| 电话铃声 | 62 | 60.00% | 14.52% |
| 流水 | 96 | 90.00% | 84.38% |
| 冲厕 | 41 | 80.43% | 90.24% |
| 吸尘器 | 25 | 100.00% | 76.00% |

默认漏检中，398次从未达到阈值，0次被候选数量限制挤出。因此单纯增加候选数解决不了大多数低分和词表缺口。开发和测试共600条均无执行失败；默认配置由开发集选择，测试集不参与调参。新真实家庭语料较早期精选素材更难，应保留上述新结果，不能用旧的较高数字替代。

参数的影响和[全部配置](configuration.zh-CN.md)分别说明。低阈值倾向多报，高阈值倾向漏报，短窗口可减少不同声音混在同一窗口的情况，但增加计算次数；扩大候选数量不能补足模型不会识别的类别。模型置信分数不是校准概率。AST输出的是分析窗口，不能当作精确事件边界。纯数字静音控制不代表自然噪声都不会误报。

## 中文情绪

**2026-10-23** 评测的[CSEMOTIONS固定修订](https://huggingface.co/datasets/ATH-MaaS/CSEMOTIONS/tree/19498e62e6745cf9ec9b69a44b826caa467eac31)提供已有表演标签。预测前选定10位说话人的690条录音，两位作开发、八位作测试，排除跨集合规范化重复文本。共同六类共120条开发、480条测试；另90条Playfulness单列，不映射“开心”，也不混入六类准确率。模型没有收到参考文字、情绪或说话人标识。

| 固定模型与处理方式 | 开发集宏平均F1 | 测试严格命中 | 测试宏平均F1 |
| --- | ---: | ---: | ---: |
| emotion2vec+base整段 | 0.327 | 226/480（47.08%） | 0.411 |
| emotion2vec+large整段 | 0.336 | 261/480（54.38%） | 0.504 |
| SenseVoiceSmall官方中文情绪模式 | 0.095 | 199/480（41.46%） | 0.382 |
| 当前base服务，FSMN门控、10秒窗口 | 0.307 | 215/480（44.79%） | 0.426 |
| 当前base服务，FireRed门控、10秒窗口 | 0.307 | 216/480（45.00%） | 0.427 |

F1综合精确率和召回率，宏平均让六类权重相同；严格命中要求输出恰好一个正确标签，多标签和弃答均不能算命中。各模型均无执行失败。large的测试分数较高，但开发集提升只有0.009，未达到事先约定的0.05替换要求，不能看到测试结果后再改规则。保留base实验接入，不升级稳定等级。

问题不只是模型大小：三个整段分类候选均没有命中任何“恐惧”测试样本；FSMN窗口服务有47条测试输出多个情绪。超过10秒的119条严格命中率31.93%，较短361条为49.03%；两组素材不同，不能据此证明单纯缩短窗口就能解决。

同一批100条自然非语音对照中，FSMN放行32条、输出情绪30条；默认FireRed放行15条、输出情绪14条。14/100的描述性Wilson 95%区间为8.53%～22.14%，30/100为21.89%～39.58%。采集规则禁止语音，不等于逐条证明不存在任何人声发声；这些数字只对应所测语料和处理路线。语音门控能减少无关输入，但仍可能把环境声当作人声；情绪分类器面对非语音仍会给标签。

表演预设标签不等于自然中文会议里的独立听者共识，公开时间较晚也不是逐文件排除训练重叠的证明。MOSS4B/8B既有英文严格命中20/96、24/96，仍是独立可选实验；这些英文结果不代表中文情绪准确率。SenseVoiceSmall只是评测对照，不是可选部署后端。不要将预测标签用于自动判断真实心理状态。

## 怎么选

| 需求 | 建议 |
| --- | --- |
| 日常转写 | 默认不选人声模型：`--voice none`，单次任务只转写 |
| 环境声索引 | `--sound ast`，任务加`--analyze-sound`；结合实际声音种类验收 |
| 稳定的音高、能量数值 | 部署加`--measurements`、任务加`--measure-voice`，无需情绪权重 |
| 实验情绪标签 | `--voice emotion2vec`、任务加`--analyze-voice`，保留模型来源、阶段状态和多标签 |
| 实验开放式人声描述 | 独立选择`--voice 4b`或`--voice 8b`，按需下载、加载和运行 |

[配置表](configuration.zh-CN.md)逐项列出所有参数和可选模型；[预先冻结的评测规则](quality-protocol.md)说明选择与分母；[验证说明](validation.md)区分源码、镜像、真实推理与干净安装。吞吐、冷启动、并发和长录音超时仍需结合实际硬件验收。

| --- | ---: | ---: |
| CPU路线 | 1.150秒 | 1.279秒 |

这是共享主机上的暖机计时，不是冷启动、并发容量或云端延迟对照。参数见[完整配置](configuration.zh-CN.md)，自己的素材可按[复现步骤](release-acceptance.md)测试。可下载JSON保留汇总计数、日期和配置，不包含任务编号、凭据或媒体。
