# Sonovect brand assets

The logo is the existing **purple butterfly** from the `brand-management` asset standard, version **1.0.0**, adopted by explicit user request on 2026-10-20. The copied SVG bytes, geometry and gradients are unchanged. These are controlled consumption copies, not an independently editable master.

| File | Approved asset ID | Use |
| --- | --- | --- |
| `butterfly-color.svg` | `mark.color.svg` | White/light backgrounds |
| `butterfly-dark.svg` | `mark.dark.svg` | Dark navy/near-black backgrounds; transparent image |
| `banner.svg` | Product layout, referencing `butterfly-dark.svg` | Keep the referenced logo file beside this layout |
| `social-preview.svg` | Product social layout, referencing `butterfly-dark.svg` | 1280 × 640; keep the original mark beside it |
| `provenance.json` | Consumption record | Asset version, source manifest SHA-256, file hashes and geometry hash |

Both READMEs reference the original SVG files directly using a theme-aware `picture` element, with the color version as fallback. There is no remote asset dependency. `Sonovect` and `Sound, structured.` remain separately typeset product text; this layout does not establish a new fixed combination logo.

The mark's coordinate canvas is 500 × 278. Scale uniformly, keep at least 0.04 × its width as clear space on every side, and use a plain appropriate background. Use the supplied color variant; do not redraw, distort, recolor, crop, mirror, add strokes/shadows/glow or alter opacity. The original standard's main files are owned by the brand project; request new variants there rather than modifying these copies.

The previous waveform/block mark has been retired from the current project presentation. Historical delivery snapshots describe their own source revision. No model, API or runtime behavior changes with this adoption.

The social preview is a bilingual product layout, not a new logo. The rendered upload image is a release-presentation asset; original SVG sources stay here.
